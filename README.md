# SAM AI Technologies — Task 2
## AI PDF Question Answering

A Streamlit application that lets a user upload a PDF, ask questions about it, and retrieve relevant answers with page context.

### Features
- Upload a PDF document
- Ask questions related to the PDF
- Extract relevant text
- Display an answer and page-level context
- Simple user-friendly interface

### Run
```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
